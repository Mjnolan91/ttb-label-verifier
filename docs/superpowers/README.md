# Historical working documents

The plans, specs, and audit notes in this directory are working artifacts from the build process,
kept for transparency. They are snapshots, not documentation: several describe designs that were
later changed or removed (for example a confirm-to-approve subsystem deleted on 2026-06-09).

For the current architecture and rules, read [`AGENTS.md`](../../AGENTS.md) and
[`specs/PROJECT_SPEC.md`](../../specs/PROJECT_SPEC.md); for the product overview, the root
[`README.md`](../../README.md).
